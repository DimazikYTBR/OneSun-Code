# ☀ OneSun Code

[English](README.md) · **Русская версия**

ИИ-агент для программирования прямо в терминале — интерфейс в стиле Claude Code.
Ты вставляешь свой API-ключ, выбираешь нейросеть, и агент читает твой проект, правит файлы и запускает команды (с твоего разрешения).

Поддерживаются: **Claude, Google Gemini (в том числе Gemini 4), OpenAI, DeepSeek, OpenRouter** и любой OpenAI-совместимый API.

## Установка (Windows)

Нужны два бесплатных инструмента:

1. **Node.js 18 или новее** — https://nodejs.org (кнопка LTS)
2. **Git** — https://git-scm.com

Затем открой PowerShell, cmd или Windows Terminal и введи:

```
git clone https://github.com/DimazikYTBR/OneSun-Code.git
cd OneSun-Code
npm link
```

(Вместо `npm link` можно просто дважды кликнуть по `install.bat`.)

## Запуск

Перейди в папку своего проекта и введи команду:

```
cd C:\Projects\my-game
onesun
```

### Первый запуск

1. **Язык.** При первом запуске программа предложит выбрать язык (по умолчанию English; стрелки + Enter или клавиши `1` / `2`). Потом его можно сменить командой `/lang`.
2. **Настройки.** Если API-ключ или модель не указаны, программа **сама откроет `config.txt` в Блокноте**.
   Впиши значения после знака `=`, сохрани файл (Ctrl+S), вернись в терминал и нажми Enter.

```
PROVIDER=gemini
API_KEY=твой-ключ
MODEL=gemini-4-argon
```

Файл `config.txt` лежит в папке OneSun-Code (его создаёт программа из шаблона) и не попадает в GitHub, поэтому ключ не утечёт.
Изменить настройки позже: команда `/config` внутри программы или `onesun --config`.

### Настройки никогда не сбрасываются

- `config.txt` создаётся **только если его ещё нет**. Существующий файл не перезаписывается ни программой, ни обновлениями (`git pull`).
- Если у тебя конфиг от старой версии без языка, программа спросит язык один раз и **допишет** в конец файла только строку `LANG=...`. Всё остальное остаётся байт в байт.
- Команды `/model`, `/provider` и `/lang` меняют только свою строку.
- Не загружай `config.txt` на GitHub вручную (например, через «Upload files»): в нём твой ключ.

## Как пользоваться

Пиши задачу обычным языком:

```
> найди, почему не работает вход, и исправь
> добавь в бота команду /stats
> создай index.html с игрой «Змейка»
```

Пока агент думает, показывается переливающийся статус (белый текст, по которому бежит синяя волна), а фраза меняется каждые пару секунд («Думаю», «Ловлю лучи», «Колдую»…).

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/config` | открыть config.txt |
| `/model имя` | сменить модель |
| `/provider имя` | сменить провайдера |
| `/lang` | сменить язык (English / Русский) |
| `/init` | агент создаст ONESUN.md для проекта |
| `/commit` | агент напишет сообщение коммита и закоммитит изменения |
| `/test` | агент найдёт и запустит тесты проекта |
| `/desktop задача` | агент работает на компьютере: открывает программы, печатает, кликает (Windows) |
| `/undo` | отменить последнее изменение файла, сделанное агентом |
| `/copy` | скопировать последний ответ в буфер обмена |
| `/mode` или **Shift+Tab** | режим разрешений |
| `/clear` | очистить диалог |
| `/exit` или Ctrl+C дважды | выход |
| **Esc** | прервать агента |

Можно сразу дать задачу: `onesun "добавь README"`.
Перенос строки — `\` в конце строки. Вставка многострочного текста работает как есть.

### Режимы разрешений

- **спрашивать разрешения** (по умолчанию) — перед правкой файла и запуском команды покажет, что именно собирается сделать, и спросит: Да / Да, больше не спрашивать / Нет;
- **правки без вопросов** — файлы правятся сами, команды спрашивают;
- **всё без вопросов** — агент делает всё сам. Используй осторожно.

Чтение файлов внутри папки проекта разрешений не требует. Чтение вне папки — спрашивает.

### Закреплённая шапка

Логотип OneSun и название (вместе с провайдером, моделью и папкой проекта) закреплены вверху экрана и не уезжают при прокрутке диалога. Шапка обновляется при смене модели.
Если окно терминала слишком маленькое (меньше 18 строк), шапка не показывается сама.
Недостаток: старые сообщения нельзя вернуть колесом мыши, они уходят за верхнюю границу области диалога. Если это мешает, поставь в `config.txt` строку `HEADER=off`.

### Папка проектов

Твои проекты живут в папке `projects` внутри OneSun-Code. Создай проект командой `/new мой-проект` (или создай папку там сам и запусти `onesun` в ней). Внутри этой папки агент правит файлы и запускает команды **без вопросов**. Везде вне её он спрашивает как обычно. Действия с компьютером (Desktop) всегда спрашивают. Папка не загружается в GitHub.

### Инструкции для проекта

Создай в папке проекта файл `ONESUN.md` — агент прочитает его при каждом запуске (стиль кода, как запускать тесты и т.п.).

## Если API заблокирован

Из некоторых стран прямой доступ к Claude, OpenAI или Google недоступен. Варианты:

- взять ключ **OpenRouter** (`PROVIDER=openrouter`) или **DeepSeek** (`PROVIDER=deepseek`);
- указать адрес прокси/зеркала в `BASE_URL=` — он работает для любого провайдера.

## Обновление

```
cd OneSun-Code
git pull
```

Если `git pull` ругается на «local changes» в каком-то файле, выполни `git restore <файл>` и повтори. Твой `config.txt` в репозиторий не входит и остаётся нетронутым.

## Если символы выглядят криво

Лучше всего работает **Windows Terminal** (в Windows 11 он стоит по умолчанию). В старой консоли программа сама переключается на простые символы; принудительно: `set ONESUN_ASCII=1`.

## Как выложить на GitHub (для автора)

```
cd OneSun-Code
git init
git add .
git commit -m "OneSun Code"
git branch -M main
git remote add origin https://github.com/DimazikYTBR/OneSun-Code.git
git push -u origin main
```

Перед `git push` убедись, что `config.txt` в списке игнорируемых (`.gitignore` уже настроен) и ключи в репозиторий не попали.
